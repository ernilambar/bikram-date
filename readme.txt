Displays post dates in Nepali.

== Description ==

This plugin helps you to display post date in Nepali format. It converts the Gregorian post date to the Bikram Sambat calendar and shows it on your site without altering the date stored in the database. You can choose to display the converted date in Nepali or English language, and customize the date format from the plugin settings.

== Frequently Asked Questions ==

= Does this plugin change the date stored in the database? =

No. It only changes how the date is displayed on the front end via the `get_the_date` and `get_the_time` filters. The original Gregorian date stored in the database is never modified.
